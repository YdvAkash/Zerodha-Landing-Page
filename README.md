# Zerodha Landing Page (Practice Project)

A static HTML recreation of parts of Zerodha's public landing page. This is a front-end learning project, not an official Zerodha website or a functional trading service.

## Preview

Open `index.html` directly in a browser. The page uses local image and SVG assets from the repository, plus an externally hosted menu icon.

## Project contents

- `index.html` — page markup and inline styling.
- `logo.svg`, `tablogo.png` — branding assets used by the page.
- `photo.png`, `ecosystem.png`, `press-logos.png`, `charges.png`, `index-education.svg`, `pricing-eq.svg` — page illustrations and graphics.

## Notes

- No package installation, build tool, or JavaScript framework is required.
- Some buttons and text links are visual examples and are not wired to real account, product, or navigation flows.
- The page reproduces static marketing content only. Do not enter credentials or financial information into this practice project.
- The copy and financial figures are illustrative of the source page and may be outdated. Refer to Zerodha's official website for current information.
